    Calculadora de datos curiosos

    Haz una operación y, si el resultado es un número del 1 al 5000, ¡te contamos un dato curioso de ciencia! Si el resultado tiene decimales, usamos su parte entera.

    0

    Dato curioso

    Todavía no hay resultado. Prueba con un número del 1 al 5000.

    Cómo usarla

    1. Pulsa números y una operación (+, −, ×, ÷).
    2. Pulsa = para ver el resultado.
    3. Si el resultado es un número entre 1 y 5000, aparece su dato curioso.
    4. Pulsa C para empezar de nuevo o ⌫ para borrar la última cifra. También puedes usar el teclado.
